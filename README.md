# Nommy's Signature Style

Build a premium, lively, modern and fully responsive e-commerce website for a Nigerian fashion brand called Nommy’s Signature, based on the business information below.

Brand Name: Augustina Nneoma Marycynthia (Nommy’s Signature)



Business Type: Clothing Brand — Wholesale & Retail



Instagram: nommysfashionworld_balogun



Head Office:

Shop BF54/56, Breadfruit Plaza, 10 Davies Street, Balogun, Lagos Island, Lagos, Nigeria.



Second Store:

Phone Numbers:

The business sells clothing through both wholesale and retail, and serves customers in Lagos as well as customers who need products delivered to other parts of Nigeria.



Do not invent a logo. Create a clean temporary text-based brand identity using “Nommy’s Signature” until the real logo is provided later.



---



OVERALL DESIGN DIRECTION



Create something that immediately feels like a real fashion business website, not an AI-generated template.



The design should be:



- Elegant

- Modern

- Fashionable

- Warm

- Lively

- Premium but still approachable

- Mobile-first

- Easy to navigate

- Suitable for Nigerian customers

- Suitable for both wholesale and retail shoppers



Use a sophisticated fashion-inspired visual style with beautiful typography, generous spacing, attractive product photography and subtle animations.



Do NOT make the website overly flashy or childish.



The animations should make the website feel alive without making it difficult to use.



Use smooth:



- Fade-in animations

- Slide-up animations

- Hover effects

- Image zoom effects

- Floating elements

- Subtle button animations

- Product card animations

- Smooth page transitions

- Animated counters/statistics where appropriate

- Gentle floating fashion-related decorative elements



Buttons can have a very subtle movement/scale effect on hover, but do not make every element shake constantly.

---



VISUAL INTERACTIONS



Add tasteful micro-interactions throughout the website.



Examples:



- Product cards gently lift on hover

- Images smoothly zoom on hover

- Buttons have subtle hover movement

- Add-to-cart animation

- Cart count updates smoothly

- Search results animate into view

- Sections fade/slide into view as the customer scrolls

- Floating WhatsApp button has a gentle pulse

- New-arrival badge has a subtle animation

- Loading animation when navigating between pages



Keep animations smooth and performant.



Do NOT overuse animations.



The website should still feel premium.



---



MOBILE RESPONSIVENESS



This is extremely important.



The majority of Nigerian customers may visit from phones.



Make the entire website excellent on:



- Android phones

- iPhones

- Tablets

- Laptops

- Desktop computers



On mobile:



- Product images must load properly

- Text must remain readable

- Buttons must be easy to tap

- Navigation must be simple

- Product grid must fit the screen

- Search must be easy to access

- Cart must be accessible

- WhatsApp button must not cover important content

- Checkout must be easy to complete



Do not allow horizontal scrolling.



---



PERFORMANCE



Optimize the website for users with slower Nigerian mobile networks.



Use:



- Lazy-loaded images

- Optimized image sizes

- Efficient animations

- Minimal unnecessary dependencies

- Responsive image handling

- Proper loading states

- Skeleton loaders where appropriate



Do not make large animations or videos slow down the website.



---



IMPORTANT CONTENT RULE



Do NOT fabricate information about the business.



Use only the information provided in this prompt.



Where information is missing, create editable placeholders rather than inventing facts.



For example:



- Delivery prices → “Contact us for delivery rates”

- Return policy → “Policy coming soon / editable”

- Wholesale minimum quantity → “Contact us for wholesale details”

- Payment methods → Make editable

- Business history → Make editable



---



FINAL EXPERIENCE



The final website should feel like:



A real Lagos fashion brand with a modern online store.



It should be visually attractive enough that the owner can immediately imagine using it for her business.



The experience should be:



Discover → Browse → Find Product → Add to Cart → Checkout → Contact/WhatsApp → Receive Order → Give Feedback → Return Again



Make the website feel welcoming, trustworthy, lively and easy to use.



Most importantly, build the UI as a professional production-ready e-commerce website, not a simple landing page.



Ensure there are no broken links, broken images, overflowing elements, console errors or unfinished-looking sections.
